# 01. 用語集（ユビキタス言語）

現場の言葉・法令の言葉・コード上の識別子を一対一に対応させるための定義集。
**ここで決めた英語識別子以外をコード内で使わない。** 同義語は「使わない語」として明記する。

---

## 1. 人・組織

| 用語 | 識別子 | 定義 | 備考 |
|---|---|---|---|
| 病院（テナント） | `Clinic` | 本システムの契約単位。飼育動物診療施設1施設に対応 | 分院は別 `Clinic`。法人単位は `Organization` として将来分離 |
| 獣医師 | `Veterinarian` | 獣医師免許を持つユーザー。**指示（CareOrder）を発行できる唯一のロール** | |
| 愛玩動物看護師 | `VeterinaryNurse` | 愛玩動物看護師法に基づく国家資格保持者。獣医師の指示の下で診療の補助を行える | 「動物看護師」は名称独占のため無資格者に使わない |
| 看護助手 | `NursingAssistant` | 無資格スタッフ。診療の補助は行えない。給餌・清掃・観察記録・体重測定など | 現場では「トリマー兼務」等さまざま |

| 主治医 | `attendingVeterinarian` | その入院の責任を持つ獣医師 | 交代しうるので履歴を持つ |
| 当直 | `onCallStaff` | 夜間・休日の担当者 | |

## 3. 入院（本システムの中核）

| 用語 | 識別子 | 定義 | 備考 |
|---|---|---|---|
| 入院 | `Admission` | ある患畜が入院してから退院するまでの一連の期間。**本システムの中核集約** | 「入院症例」も同義 |
| 入院番号 | `Admission.admissionNo` | 病院内で一意の番号 | |
| 病棟 | `Ward` | 一般病棟・ICU・隔離室・猫専用など、ケージのグループ | 犬猫を物理的に分けるのは動物病院では必須 |

| ケージボード | — | 全入院患畜の状態を1画面で俯瞰する画面 | 現場のホワイトボードのデジタル置換。**主力画面** |
| 隔離 | `isolationLevel` | 感染症（パルボ、猫カリシ等）による隔離レベル | 動線・担当者の制限に使う |
| 酸素室 | `oxygenCage` | 酸素濃度を管理するケージ | ケージの属性として持つ |
| 面会 | `Visit` | 飼育者の面会 | Phase 2 |
| 申し送り | `Handover` | シフト交代時の情報引き継ぎ | **「引き継ぎ」も同義。コードは `Handover`** |
| シフト | `Shift` | 日勤・準夜・深夜など勤務帯 | 病院ごとに定義が違うためマスタ化 |

### 入院の状態

| 状態 | 識別子 | 意味 |
|---|---|---|
| 入院予定 | `SCHEDULED` | 手術予定等で事前登録された状態 |
| 入院中 | `ADMITTED` | 実際に収容されている |
| 退院済 | `DISCHARGED` | 通常退院 |
| 死亡退院 | `DECEASED` | 入院中に死亡 |
| 転院 | `TRANSFERRED` | 二次診療施設等へ転送 |
| 取消 | `CANCELLED` | 予定が取り消された（`SCHEDULED` からのみ） |

## 4. 指示と実施 — **概念を厳密に3層に分ける**

現場では「オーダー」「指示」「処置」が混然と使われるが、本システムでは以下を**明確に別物**として扱う。ここが設計の肝。

| 層 | 用語 | 識別子 | 定義 |
|---|---|---|---|
| ① 指示 | 入院指示 | `CareOrder` | 獣医師が発行する「何を・どれだけ・どの頻度で行うか」の**意思**。例:「セファゾリン 22mg/kg IV 8時間毎」 |
| ② 予定 | ケアタスク | `CareTask` | 指示をスケジュールに展開した**個々の予定**。例:「7/31 08:00 セファゾリン投与」 |
| ③ 実績 | 実施記録 | `CareRecord` | そのタスクを**誰がいつ実際に行ったか**。例:「7/31 08:12 山田（愛玩動物看護師）が実施、実投与量 1.1mL」 |

この分離により「指示はあるが未実施」＝`CareTask.status = MISSED` が機械的に検出できる。これが未実施アラートの源泉であり、製品価値の中心。

| 用語 | 識別子 | 定義 | 備考 |
|---|---|---|---|
| 指示種別 | `CareOrderType` | 投薬 / 輸液 / 処置 / 検査 / 食餌 / 観察 / 安静 | 下表参照 |
| 口頭指示 | `verbalOrder` | 獣医師が不在時に口頭で出した指示。**後追いで獣医師の承認が必要** | 承認されるまで未承認フラグが立つ |
| 中止 | `DISCONTINUED` | 指示を途中で止めること | 削除ではない。履歴は残る |
| 頓用 | `PRN` | 必要時に実施する指示（例: 発熱時に解熱剤） | スケジュール展開しない。実施条件を持つ |
| 実施予定時刻 | `CareTask.scheduledAt` | いつ実施すべきか | |
| 許容幅 | `CareTask.graceMinutes` | 何分ずれても「時間通り」とみなすか | 病院ごとに設定 |
| 未実施 | `MISSED` | 許容幅を過ぎても実施記録がない状態 | アラート対象 |
| スキップ | `SKIPPED` | 理由をつけて意図的に実施しなかった | 理由必須 |

### 指示種別（CareOrderType）

| 種別 | 識別子 | 例 | 必要資格 |
|---|---|---|---|
| 投薬 | `MEDICATION` | 抗生剤の静注、内服 | 愛玩動物看護師以上 |
| 輸液 | `FLUID` | 乳酸リンゲル 4mL/kg/hr、CRI | 愛玩動物看護師以上 |
| 処置 | `PROCEDURE` | 創傷処置、包帯交換、導尿 | 内容による |
| 検査 | `LAB` | 血液検査、レントゲン | 採血は愛玩動物看護師以上 |
| 食餌 | `FEEDING` | a/d缶 30g × 3回/日 | 資格不要 |
| 観察 | `OBSERVATION` | バイタル 4時間毎測定 | 資格不要（測定のみ） |
| 安静・運動 | `ACTIVITY` | ケージレスト、1日2回散歩 | 資格不要 |

## 5. 記録・計測

| 用語 | 識別子 | 定義 | 単位 |
|---|---|---|---|
| バイタルサイン | `VitalSign` | 生体の基本指標をまとめた1回の測定 | — |
| 体温 | `bodyTemperature` | 直腸温 | ℃ |
| 心拍数 | `heartRate` | | 回/分 (bpm) |
| 呼吸数 | `respiratoryRate` | | 回/分 |
| 血圧 | `systolicBP` / `diastolicBP` / `meanBP` | 非観血的または観血的 | mmHg |
| 酸素飽和度 | `spo2` | パルスオキシメータ | % |
| 毛細血管再充満時間 | `crt` | CRT | 秒 |
| 粘膜色 | `mucousMembraneColor` | 淡紅／蒼白／黄疸／チアノーゼ等 | 列挙 |
| 意識レベル | `consciousnessLevel` | 正常／沈鬱／昏迷／昏睡 | 列挙 |
| 疼痛スコア | `painScore` | 疼痛評価スケールの点数 | 使用スケールを併記 |
| IN/OUT | `IntakeOutput` | 摂取と排泄の収支記録 | — |
| 飲水量 | `waterIntake` | | mL |
| 摂餌量 | `foodIntake` | 給餌量と実際に食べた量は**別に持つ** | g |
| 尿量 | `urineOutput` | | mL |
| 便性状 | `fecalScore` | ブリストル様スケールまたは病院独自 | 列挙 |
| 嘔吐 | `vomitingEvent` | 回数と性状 | — |
| 体重 | `Weight` | **投与量計算の基準となるため独立して管理** | kg |

> **体重を独立エンティティにする理由**: 投与量は体重に比例する。入院中に体重が変わったとき「どの時点の体重で計算された指示か」を追えないと、量の誤りを検証できない。`CareOrder` は参照した `Weight` の ID を保持する。

## 6. 投与量計算

| 用語 | 識別子 | 定義 |
|---|---|---|
| 用量 | `dosePerKg` | 体重1kgあたりの投与量（mg/kg など） |
| 総投与量 | `totalDose` | `dosePerKg × weightKg` |
| 薬液濃度 | `concentration` | 製剤中の有効成分濃度（mg/mL） |
| 投与容量 | `volumeToAdminister` | `totalDose ÷ concentration`（mL） |
| CRI | `constantRateInfusion` | 持続点滴。単位時間あたりの投与を続ける |
| 投与速度 | `infusionRate` | 輸液ポンプに設定する速度（mL/hr） |
| 投与経路 | `route` | IV（静脈内）/ IM（筋肉内）/ SC（皮下）/ PO（経口）/ IO（骨髄内）/ PR（直腸） |
| 上限用量 | `maxDosePerKg` | 種別ごとの上限。超過時は警告 |
| 種別禁忌 | `speciesContraindication` | 特定の動物種に投与してはならない薬剤（例: 猫にアセトアミノフェン） |

計算式は `03-domain-model.md` の「投与量計算」節に定義する。

## 7. 費用・保険

|---|---|---|---|
| 費用明細 | `BillingItem` | 実施記録から積み上がる課金対象行 | Phase 1 は**エクスポートのみ**、請求はレセコン側 |

## 8. 使わない語

混乱を招くため、コードにもドキュメントにも書かない。

| 使わない語 | 代わりに使う語 | 理由 |
|---|---|---|
| `Customer` | `Owner` | 法令用語は「所有者又は管理者」 |
| `Pet` | `Patient` | 診療対象としての性格を明確にする |
| `Animal` | `Patient` / `Species` | 曖昧 |
| 「カルテ」（コード内） | `MedicalRecord` | 日本語表記はUIのみ |
| 「オーダー」単独 | `CareOrder` | 検査オーダーと投薬指示が混ざる |
| 「診断」「判定」（UI文言） | 「記録」「表示」 | 動物用医療機器プログラム該当性を避けるため（`02-regulatory-requirements.md` §6） |
| 「動物看護師」（無資格者に対して） | `NursingAssistant` | 愛玩動物看護師法の名称独占 |
