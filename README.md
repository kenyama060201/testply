# 獣医療 入院管理システム

動物病院の**入院中の動物のケア**に特化した記録・管理システム。

現場のホワイトボード・入院ノート・投薬チェック表を1つにまとめ、
**「指示されたケアが、資格を持つ人によって、時間通りに実施されたか」を機械的に追跡できるようにする**ことを目的とする。

## 設計の要点（3行で）

1. **指示（CareOrder）・予定（CareTask）・実績（CareRecord）を厳密に3層に分ける。** これにより「指示はあるが未実施」を機械的に検出できる。これが製品価値の中心。
2. **愛玩動物看護師法に基づく資格ベースの実施権限をサーバ側で強制する。** 2022年施行の法改正に対応しており、既存製品の空白地帯。
3. **法定記録は append-only。** 訂正は追記であって上書きではない。アプリ用DBロールから UPDATE / DELETE 権限を剥奪する。

## 作らないもの（意図的な決定）

- 外来カルテ・レセプト・会計の本体 — 既存レセコンと共存する
- 診断支援・重症度の自動判定 — 動物用医療機器プログラム該当リスクを避ける
- オンライン診療 — 農水省指針の対象。背負う必然性がない
- ペット保険の窓口精算 — 保険会社の仕組みで、単独では実現できない

詳細と理由は [docs/00-scope-and-principles.md](docs/00-scope-and-principles.md) を参照。

## 注意

- 本リポジトリのドキュメントは開発方針を決めるための調査に基づくものであり、**法的助言ではない**。事業化前に獣医療に詳しい弁護士および所管官庁への確認を行うこと。
- 市場データは調査時点（2026年7月）のもの。事業計画に使う前に最新版で再確認すること。
- 投与量計算は動物の生命に直結する。実装時は単体テストのカバレッジ100%、および獣医師による実処方例での突き合わせを必須とする。
